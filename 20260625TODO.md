## MVP priority list

### P0 — must fix before SaaS testing

1. Navigation hygiene / no dead promises
   - Add a “Route readiness” checklist for every menu item: `Live`, `Preview/hidden`, `Coming soon disabled`, or `Remove from MVP`.
   - Hide or disable route-backed Projects links until project routes exist.
   - Standardize disabled items with clear “Coming soon” labels and no clickable broken paths.
   - Value: prevents testers from losing trust in the product before they reach the accounting workflow.

2. Bookkeeping Command Centre
   - Add a top-level or Dashboard widget called `Bookkeeping Command Centre`.
   - Show: unreconciled bank transactions, invoices needing review, statements needing reconciliation, unpaid/overdue supplier bills, unpaid/overdue customer invoices, VAT deadline/status, missing account mappings, failed extractions, and unposted journals.
   - Value: one place to know “what must I do today to keep the books clean?”

   - Sprint 2 status: initial dashboard widget is live using existing bank, invoice, approval, journal, extraction, and bank mapping records. VAT deadline/status and richer supplier settlement state remain follow-up refinements.

3. Setup / Go-Live Wizard
   - Add to Settings or Dashboard: `Go-Live Checklist`.
   - Steps: organisation details, VAT/PAYE numbers, financial year, chart of accounts, bank accounts, opening balances, users/roles, tracking dimensions, invoice branding, supplier/customer import, test transaction post.
   - Value: reduces onboarding variation and support load.
   - Sprint 3 status: initial dashboard checklist is live using existing organisation, chart, bank, user, tracking, branding, master-data, opening-balance, and posted-journal signals. No database migration was required.

4. Period close and lock dates
   - Add Settings > Accounting Periods.
   - Include financial year setup, monthly close status, lock date, reopen permission, and close checklist.
   - Value: prevents accidental edits after VAT/month-end and supports audit discipline.
   - Sprint 4 status: Settings > Reports now includes Accounting Periods & Lock Dates with open/closed/locked statuses, a close checklist, notes, an effective lock-date display, and cross-module posting rejection for locked dates.

5. Core financial reports menu completeness
   - Existing live reports: Trial Balance, Transactions, VAT.
   - Add MVP report routes/placeholders for:
     - Profit & Loss / Income Statement
     - Balance Sheet
     - General Ledger
     - Aged Payables
     - Aged Receivables
     - Cash Flow summary
   - Value: without these, testers cannot validate the product as an accounting system.

6. VAT/SARS workspace
   - Expand Reports > VAT into `VAT/SARS`.
   - Add VAT201 summary, VAT audit drilldown, exceptions, export pack, filing period status, and deadline reminders.
   - Value: South African SaaS accounting credibility depends heavily on VAT compliance.
   - Sprint 5 status: VAT report API/export now carries SARS-facing summary fields, structured review exceptions, warning counts, and richer CSV/TXT/XLSX audit output. Filing period workflow/deadline reminders remain follow-up UI work.

7. Bank/Cash Rules Manager
   - Add Bank/Cash > Rules.
   - Include rule list, priority order, test rule against historic transactions, duplicate detection, rule audit log, and enable/disable.
   - Value: turns reconciliation from manual processing into repeatable automation.
   - Sprint 6 status: backend manager API is live for listing rules with usage stats, editing priority/active state/match criteria, and testing rules against recent bank transactions. Frontend route/menu activation and deeper duplicate detection remain follow-up UI work.

8. Opening balances and data import
   - Add Settings > Data Import / Opening Balances.
   - Import: chart of accounts, suppliers, customers, inventory items, opening trial balance, unpaid supplier/customer balances, bank opening balances.
   - Value: essential for onboarding real businesses without bespoke database work.
   - Sprint 7 status: backend opening trial-balance preview/post API is live. It resolves account IDs/codes, validates debit/credit balance, posts a protected GL opening-balance journal, prevents duplicate opening journals for the same date, and respects lock dates. CSV/UI upload and master-data import templates remain follow-up work.

9. Bookkeeping Health Score
   - Add dashboard score from objective checks:
     - unreconciled bank age
     - unposted journal count
     - supplier/customer missing tax or banking data
     - VAT exception count
     - aged receivable/payable risk
     - unmatched statements
   - Value: simple visual control for business owners and accountants.

   - Sprint 2 status: initial score is live from unreconciled bank age/count, invoice review/posting queues, overdue receivables, approvals, draft journals, failed extractions, and missing bank GL mappings. VAT exceptions and supplier/customer master-data hygiene should be folded in once those workspaces are hardened.

10. Audit trail viewer
   - Add Settings/Admin > Audit Trail, or Tools > Audit Trail.
   - Search by user, entity, date, action, transaction, supplier, customer.
   - Value: necessary for trust, support, fraud prevention, and accountant review.
   - Sprint 8 status: audit trail API and Admin UI are live. The viewer normalizes generic audit rows, bank audit events, invoice extraction events, and sales invoice events into one searchable/filterable feed with source, entity, user, date, and text filters.

## MVP acceptance criteria before external SaaS pilot

- No visible menu item should navigate to a missing route.
- Every live menu item should support a complete happy path with demo data.
- A tester should be able to:
  1. set up an organisation;
  2. import/open balances;
  3. upload supplier/customer/bank documents;
  4. reconcile bank transactions;
  5. post journals;
  6. produce Trial Balance, Profit & Loss, Balance Sheet, VAT, AP ageing, and AR ageing;
  7. close/lock a period;
  8. export an audit pack.
- Dashboard should show what work remains, not just static totals.
- VAT exceptions and bank suspense items should be impossible to miss.
